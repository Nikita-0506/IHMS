Authority Guide

Every row has direct admin control actions.

1. Grant Access: activate and verify user.
2. Reject Access: deactivate user login.
3. Change Role: switch authority/permission role.
4. Edit: update profile details quickly.
5. Remove: soft-delete user from active records.
6. Notify: send direct notification to one user.

When "Selected Users" scope is used, checked users receive the bulk notification.
